# Contributing

AJ's Character Manager is in early development. Issues and focused pull
requests are welcome, especially when they improve the current roadmap phase.

Before starting substantial work, open an issue so scope and design can be
agreed without wasting effort. Keep changes small, explain the user-visible
reason for them, and update relevant documentation and tests.

## Development expectations

- Follow the setup and checks in [Development](docs/DEVELOPMENT.md).
- Keep UI, application logic, rules, content, and persistence concerns
  separated as described in [Architecture](docs/ARCHITECTURE.md).
- Do not claim planned behavior is already implemented.
- Do not add secrets, local databases, private campaign material, or generated
  build output.

## Rules and content contributions

Rules corrections must identify their edition and provide provenance. Explain
both the source and why the proposed data may be redistributed. A public web
page is not automatically licensed for republication.

Do not submit copyrighted text, images, logos, or structured data unless the
project can redistribute them. Content based on SRD 5.2.1 must preserve its
required attribution. See [Source of Truth](docs/SOURCE_OF_TRUTH.md) and
[Content and Licensing](docs/CONTENT_AND_LICENSING.md).

By contributing original code or documentation, you agree that it may be
distributed under the repository's MIT License. Content with another license
must be clearly identified and reviewed before inclusion.

## Conduct and security

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). Report
vulnerabilities through the private process in [Security](SECURITY.md), not a
public issue.
